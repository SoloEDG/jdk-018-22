# GLYPH ASCII Studio

安装：`npm ci`

本地启动：`npm run dev`

Docker 启动：`docker compose up --build`，访问 http://localhost:18018。

## 排版语义

- **密度 = 屏幕列数**：一列固定占 8 个虚拟像素宽、16 个像素高。字符预览、PNG 导出、
  行数与长宽比都以屏幕列为准，与字符集是拉丁、中文还是 emoji 无关。
- **逻辑字符簇**：自定义字符按字形簇（组合符、ZWJ、肤色、旗帜、变体选择符）切分，
  不会把组合符拆成独立字符。
- **目标显示环境**：终端、中日韩终端、网页 `<pre>`、严格单列。环境声明字体栈与
  East Asian Ambiguous 的宽度，切换环境时会同步重置字体栈。
- **单列安全模式**：无法占据一列的字符替换为同色阶的单列占位符（零宽字符替换为空格），
  所有替换都会列在「已替换字符」清单中。
- **保留原始字符模式**：双宽字符占用两列真实网格并写入续格，行末放不下时改为邻近的
  单列字符并记录；零宽字符前加一个基字符，避免吞掉相邻列。
- **尾部空白**：文本预览、复制、`.TXT` 导出共用同一字符串，包含每行完整的尾部空白。
- **失败回退**：字体不可用、非等宽、环境不支持双宽占位时，保留上一版网格并提示原因；
  环境/字体/模式切换会丢弃在途的旧测量结果，不会混用新旧布局。
